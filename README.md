# Xiao-air.github.io

Bilingual personal career timeline site for GitHub Pages.

## Local Development

```powershell
pnpm install
pnpm test
pnpm build
pnpm dev
```

## Content

Public career entries live in `src/content/career/zh` and `src/content/career/en`.
Keep sensitive retrospectives in the private `career-vault` repository instead of this public site.
